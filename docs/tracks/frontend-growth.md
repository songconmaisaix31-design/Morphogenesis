# 序幕 G 轨：自生长概念拓扑

## 交付

- `viz/frontend/src/intro/GrowthIntro.jsx` 默认导出 `GrowthIntro({ active, reducedMotion })`。由 S 轨负责挂载和序幕计时。
- 黑底 `#070b0d` 上的固定 SVG 拓扑从中心向外逐枝显现，辅以少量较淡的交叉连线。下方显示小字「自生长 / AGENT SWARM」及常显的「概念动画」。
- `active=false` 暂停 CSS 动画；`reducedMotion=true` 或系统减少动态效果时立即显示完整静态画面。窄屏放大中心结构，保留文字空间。没有鼠标或触屏事件，没有新增依赖。
- 节点和边均为本地固定视觉元素。组件不请求、读取或映射 `/api/dashboard`，也不表达真实成员、任务或检查点。真实拓扑由后台的数据区负责。
