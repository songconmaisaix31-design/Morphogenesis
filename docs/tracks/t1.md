## Public API and boundaries

```python
from bridge_node import NodeAssetBridge, LocalGepMcpClient

sdk = NodeAssetBridge(timeout_seconds=10)
canonical_json = sdk.canonicalize({"b": 2, "a": 1})
asset_id = sdk.compute_asset_id(full_asset)
hash_matches = sdk.verify_asset_id(full_asset)
validation = sdk.validate_asset(full_asset)
# validation.valid = validation.schema_valid AND validation.asset_id_valid
# validation.errors contains schema paths/keywords, never submitted field values.

async with LocalGepMcpClient(isolated_workspace).connect() as session:
    tools = await session.list_tools()
    result = await session.call_tool("gep_recall", {"query": "error"})
```

- `NodeAssetBridge` starts an absolute Node executable with `shell=False`, writes one UTF-8 JSON request to stdin, and reads one structured JSON result. stdin collection in Node is asynchronous. Input is bounded to 2 MiB; NaN/Infinity are rejected. Timeout defaults to 10 seconds; Python `subprocess.run` kills and waits on timeout. Start errors, malformed output, nonzero exit, SDK errors, and timeouts become sanitized `BridgeError.code` values. No automatic retry or Python hash fallback is present.
- Ajv uses the schemas exported by the installed SDK; it does not coerce types, fill defaults, or strip fields. Hash validity and schema validity are separate results. Schema acceptance is local evidence, not proof of Hub acceptance or of true task outcome.
- MCP is the main behavioral API, through the official Python SDK's initialize/list-tools/call-tool protocol. Node SDK subprocesses are used only for asset canonicalization/hash/schema validation. There is no Evolver CLI path in this worker. A pure Python HTTP fallback belongs to Hub and cannot claim official SDK validation when this bridge fails.
- The MCP client checks the server package and initialized server version are 1.7.0, sets a request deadline, closes stdio/session/process through SDK context managers, and refuses further use after a timeout or closed context. Caller exceptions are preserved across anyio task groups. Upstream stderr and protocol error data are not forwarded to logs/exceptions. No remote effect is retried.
- Allowed local calls: `gep_recall`, `gep_evolve`, `gep_export`, `gep_status`, `gep_protocol_info`, `gep_list_genes`, `gep_install_gene`, `gep_record_outcome`. Discovery returns official tools, but every call is checked against the allowlist. Installs require official schema and content ID validation. Evolve returns upstream planning data; it does not execute the plan or its returned instructions.
- Export uses only `<workspace>/assets/export.gepx`. The pinned upstream path guard uses `/` on Windows and falls back to that path; the adapter exposes the stable destination consistently instead of promising arbitrary paths. The upstream export requires `tar`; its archive/manifest is not a new project completion-proof system.

## Local mode and isolation audit

MCP Server 1.7.0 `src/index.js` chooses remote mode when `(EVOMAP_API_KEY || EVOMAP_NODE_SECRET) && EVOMAP_NODE_ID` is truthy, and otherwise creates `GepRuntime`. Its default Hub URL is production. Local mode still exposes `gep_search_community`, which can fetch the Hub; merely unsetting the API key is insufficient for an offline boundary.

The child environment explicitly empties both credentials, Node ID, `NODE_OPTIONS`, and `NODE_PATH`; sets the Hub URL to a nonproduction loopback discard endpoint; and confines HOME/USERPROFILE, temporary directories, GEP assets/memory and skills roots to the supplied workspace. Network/community/publish/revoke/report/skill calls are not allowed through the adapter. Only OS process discovery essentials are inherited. No credential is printed, stored in a model repr, or committed. This isolates the known runtime's data/configuration; it is not an OS sandbox for hostile code.

Tests use a fresh pytest workspace per run. MCP uses stdio and opens no listening port. No Hub production/sandbox request is needed or authorized by these tests. Raw complete asset bodies, MCP responses and returned instructions remain untrusted data.
