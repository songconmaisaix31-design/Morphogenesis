# T5 展示轨

## 输入与边界

- 已合并 T0 初版契约 `d0f5ac9bd75b8b8f1bc12d0d22b625d549833a71`，读取 `Envelope`、`Gene` 与三态 `Acceptance` 的既有字段，不修改契约或依赖锁。
- 实际运行输入为 T2 的受限 evidence root：`events.jsonl`（`export_events` 的 JSONL `Envelope`）、`result.json`（`TaskResult`）、`genes.json`（T3M `GeneView[]`）和 `adoption.json`（当前 run `UseRecord[]`）。每项经共享 Pydantic 模型重验；T5 不从 event payload 推测 Gene、指标或任务成功。
- `demo/data/mock-run.json` 是唯一的文档型输入，且文档入口强制 `provenance=mock`；页面及 API 统一标出 `mock`。任何 JSON 文档声称为 `live/replay` 均会被拒绝，真实来源只能走 T2 JSONL。mock/replay 一旦声称 `interface_live` 或 `task_live=passed` 也会被拒绝。
- 不接受 URL、请求参数或任意磁盘路径；服务只绑定 `127.0.0.1`，并限制 allowlist、扩展名和 2 MiB 文件大小。页面内容以 DOM `textContent` 写入，不插入输入字符串为 HTML。
- ECharts 全部 tooltip 强制 `renderMode: "richText"`，不在 tooltip formatter 返回 HTML；runtime `GeneView` 与 `UseRecord` 的 provenance 必须和 `TaskResult` 一致，混合来源会拒绝加载。

## 展示

- `viz/static/` 仅加载本地 `/vendor/echarts.min.js`；服务只映射 T0 `package-lock.json` 锁定的 `node_modules/echarts/dist/echarts.min.js`（ECharts 6.1.0，Apache-2.0）。包依赖/锁文件仍由 T0 所有，运行前执行 `npm ci`。
- Gene 图仅显示 `GeneView.source_attempt`、相同 `gene_id` 的显式版本和 `UseRecord` 采用边；相似候选、事件 payload 与结果不会被伪造为谱系。消息图直接取 Envelope 发送方、接收方和消息类型。
- 指标区分当前、历史均值、历史最佳，但在输入没有 `metrics[].history` 时显示空态，不预设上升。Hub 配置缺失统一显示“待发布（未配置 Hub 沙箱）”。
