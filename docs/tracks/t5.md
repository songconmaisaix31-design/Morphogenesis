# T5 展示轨

## 输入与边界

- 已合并 T0 初版契约 `d0f5ac9bd75b8b8f1bc12d0d22b625d549833a71`，读取 `Envelope`、`Gene` 与三态 `Acceptance` 的既有字段，不修改契约或依赖锁。
- 实际运行输入为 T2 `orchestration.events.export_events(store, run_id, destination)` 的 JSONL `Envelope` 导出，只允许从 `runtime_exports/` 读取；每行经 T0 的 `Envelope.model_validate` 重验后只渲染消息流。T5 不将事件 payload 推测为 Gene、指标或任务成功。
- `demo/data/mock-run.json` 是唯一的 mock 文档输入，页面及 API 统一标出 `mock`。mock/replay 一旦声称 `interface_live` 或 `task_live=passed` 会被拒绝。
- 不接受 URL、请求参数或任意磁盘路径；服务只绑定 `127.0.0.1`，并限制 allowlist、扩展名和 2 MiB 文件大小。页面内容以 DOM `textContent` 写入，不插入输入字符串为 HTML。

## 展示

- `viz/static/` 采用 Apache-2.0 的官方 Apache ECharts CDN `5.5.1`（固定版本）。包依赖/锁文件仍由 T0 所有。
- Gene 图仅将同一 `gene_id` 的显式版本连接为谱系；没有 Gene 正文就显示空态。消息图直接取 Envelope 发送方、接收方和消息类型。
- 指标区分当前、历史均值、历史最佳，但在输入没有 `metrics[].history` 时显示空态，不预设上升。Hub 配置缺失统一显示“待发布（未配置 Hub 沙箱）”。

## 验证范围

```powershell
python -m unittest discover -s tests/t5 -v
python -m viz.server --port 7500 --input demo/data/mock-run.json
```

第二条用于浏览器视觉检查且只证明 mock 布局。真实 `task_live` 仍依赖 T0 bootstrap、T2 实际执行/JSONL 导出以及所需真实接口证据；本轨没有把这些未提供的远端或运行时结果标为通过。
