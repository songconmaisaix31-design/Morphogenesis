# T2 execution runtime

## Scope and API handoff

Only `orchestration/**`, `tests/t2/**`, and this file are owned by T2.
Contracts imported from T0 `d0f5ac9bd75b8b8f1bc12d0d22b625d549833a71`;
no contract freeze or live acceptance is claimed at this stage.

`orchestration.events.export_events(store: EventStore, run_id: str,
destination: str | Path) -> int` writes a UTF-8 JSONL snapshot of full Envelope
objects ordered by `(seq, msg_id)`. It returns the event count and does not
change handled/provenance/acceptance. T5 can read each line with
`Envelope.model_validate_json(line)`. Store construction belongs to T0;
visualization does not require LangGraph imports.

Planned graph: select/inject -> execute -> independent verify -> feedback.
Use `SqliteSaver.from_conn_string` as a context manager and `thread_id` for
restart. Persist an execution intent using T0 EventStore *before* calling CLI;
if this node replays with an existing intent, conservatively block rather than
repeat an uncertain external action. This is not an exactly-once claim.

## Reuse and execution boundary

- Installed public CLI: `codex-cli 0.155.1`; local `codex exec --help` confirms
  `--sandbox read-only`, `--json`, `--output-schema`, `--output-last-message`,
  `--ephemeral`, `--ignore-user-config`. Upstream Apache-2.0; no source copied.
- [Codex noninteractive documentation](https://developers.openai.com/codex/noninteractive)
  is supplemental to the installed help. The CLI produces structured proposals;
  a narrow adapter applies only the fixed `sample.py` artifact. Tests remain
  outside the task workspace. No sandbox bypass option is used.
- [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence):
  official StateGraph and SQLite checkpointer, MIT. T0 owns dependency locking.
  Checkpoints store graph state, not OS processes or filesystem transactions.
- Independent review uses T0's fixed SampleVerifier and a distinct reviewer
  identity, requiring no second model call. This is deterministic verification,
  not a claim of a second model reasoning about the repair.
