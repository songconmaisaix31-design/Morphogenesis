`persistence.SQLiteStore(path)` implements the three store protocols plus save/get_provision and close. Events deduplicate `(run_id,msg_id)`; conflicting payloads raise ValueError, identical duplicate returns False. Results key `(run,task,agent,attempt)` and may progress through review. `bootstrap.sample.prepare_workspace(path)` materializes only `sample.py` and `TASK.md`, refuses nonempty destinations. `bootstrap.verify.SampleVerifier(evidence_dir).verify(workspace,reviewer)` executes fixed cases in a separate Python process against a snapshot and stores durable output outside executor workspace. T2 must sandbox the executor to the prepared root with only sample.py writable; no claim of OS isolation from path layout alone. The verifier is for the benign fixed exercise, not a general hostile-code sandbox. CLI: `python -m bootstrap prepare|verify --workspace PATH`.
