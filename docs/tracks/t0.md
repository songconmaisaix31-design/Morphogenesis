# T0 foundation API handoff

Stage 1: contracts and local implementation prepared; dependency install, semantic tests, strict typecheck and build are still pending. This initial handoff does not freeze untested interfaces or claim live acceptance.

Packages are at the repository root. Import contracts directly (not `src.contracts`). Models use Pydantic v2, forbid extra keys and freeze attribute assignment. Use `model_validate` / `model_validate_json` for external data, not `model_copy(update=...)` which bypasses validation.

| API | Required fields / behavior |
|---|---|
| `contracts.identity.AgentId` | `role`: planner/builder/reviewer/aggregator; `instance >= 0`; hashable |
| `AttemptId` | `task_id`, `agent: AgentId`, `attempt >= 0`; business data only |
| `contracts.messages.Envelope` | `run_id,msg_id,msg_type,sender,receiver,task_id,attempt,seq,ts`; `receiver` AgentId or broadcast; optional `artifact_uri,payload,handled,provenance,original_run_uri` |
| `contracts.resolution.GeneRef` | `gene_id`, `version=1`, `asset_id=None` |
| `Gene` | `ref,signals_match,strategy`; optional `avoid,verification,provenance,source_attempt`; internal model, T1 translates official schema |
| `contracts.results.Verification` | `passed: bool or None`, `reviewer`, `evidence: list[str]`, `command: list[str]`, `exit_code`, `summary`; pass requires reviewer, evidence, exit 0 |
| `TaskResult` | `run_id,task_id,attempt,status`; `verdict,artifact_uri,provenance,original_run_uri,acceptance,usage`; success requires independent reviewer and artifact |
| `Usage` | `tokens,cost_usd`: nonnegative or `None` for unknown; never invent zero |
| `contracts.provenance.Acceptance` | Independent `contract_local,interface_live,task_live`: not_run/passed/failed/blocked; `provenance`, `original_run_uri`; mock/replay cannot pass live dimensions |
| `contracts.runtime.RunConfig` | `run_id,workspace,writable_paths`; max_tokens 20000, max_cost_usd 1, max_retries 1, no_progress_limit 2, timeout_seconds 120, gene_budget 3; approval always required, unknown_usage_policy stop |
| `Provision` | `provision_id,run_id,requested,members`; `source` fixed/orca, `quota` optional, `provenance,external_ids`; no ORCA runtime assumptions |

`contracts.protocols` defines `TopologyEngine.select(targets)/record(attempt,success)/snapshot()`, `PipeState`, `EventStore`, `ResultStore`, `GeneStore`, synchronous `Executor.execute(attempt,config,genes)`, `Verifier.verify(workspace,reviewer)`, `Provisioner.provision(run_id,count)`. Metabolism Protocol is in `contracts.resolution`: ingest/resolve/inject/mark_used/decay_weights/merge_candidates/archive as development v2. Implementers must exercise their concrete calls before freezing these integration points.

`persistence.SQLiteStore(path)` implements the three store protocols plus save/get_provision and close. Events deduplicate `(run_id,msg_id)`; conflicting payloads raise ValueError, identical duplicate returns False. Results key `(run,task,agent,attempt)` and may progress through review. Gene version content is immutable; asset-id mismatch rejects resolution. This stores metadata only; use the official SqliteSaver context manager for graph state.

`bootstrap.sample.prepare_workspace(path)` materializes only `sample.py` and `TASK.md`, refuses nonempty destinations. `bootstrap.verify.SampleVerifier(evidence_dir).verify(workspace,reviewer)` executes fixed cases in a separate Python process against a snapshot and stores durable output outside executor workspace. T2 must sandbox the executor to the prepared root with only sample.py writable; no claim of OS isolation from path layout alone. The verifier is for the benign fixed exercise, not a general hostile-code sandbox. CLI: `python -m bootstrap prepare|verify --workspace PATH`.
