## 六、评审准备详表

### 6.1 答辩快答（随身卡片）

见《作战方案 v2》§11（管道公式、Gene vs Prompt、衰减理由、Hub 接入、容错、竞品差异），熟练到 30 秒内可答。

### 6.2 5 分钟路演脚本

| 段 | 时长 | 内容 |
|---|---|---|
| 开场 | 30s | 壳与幽灵：一堆 Agent 实例，如何长出不属于任何一个的集体策略 |
| 现场运行 | 90s | 真实任务，intent/result/signal 消息流实时滚动 |
| 解释层 | 60s | 黏菌启发式权重更新 + 经验整理，含公式与**边界声明** |
| 结果 | 60s | 区分当前/均值/历史最佳的指标图（**不预设单调上升**） |
| 结尾 | 30s | 「我们进化出的 Gene 已在 Hub 上被其他节点获取并适配」 |

### 6.3 降级预案（现场保稳定）

| 风险 | 降级动作 |
|---|---|
| Hub 不可达 | 切 `mocks/hub.py`，演示用本地资产 |
| 外层进化成本高 | T4 移出主链（可选）；代理评估仅作**筛选**，其分数**不得**冒充真实适应度 |
| 某模块崩 | 切 mock，保留已就绪真实模块 |
| 网络/硬件故障 | 预录演示视频兜底 |
